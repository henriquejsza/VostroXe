# MGLShim — route an unmodified native app's OpenGL to MGL

`mglshim.m` is a `DYLD_INSERT_LIBRARIES` dylib that makes a native macOS app (one that uses
`NSOpenGLContext` / `NSOpenGLView`) render through [MGL](../MGL) (OpenGL 4.6 → Metal on the Iris Xe)
instead of Apple's software renderer, **without recompiling the app**. See [../../docs/OPENGL.md](../../docs/OPENGL.md).

How it works:
- **Context lifecycle** — swizzles `NSOpenGLContext` (`initWithFormat:` → an MGL `GLMContext`, shared
  contexts map to one; `setView:` → MGL's `CAMetalLayer` on the app's view; `makeCurrentContext` →
  `MGLsetCurrentContext` and raises `mglshim_active`; `flushBuffer` → `MGLswapBuffers`) and strips
  `NSOpenGLPFAAccelerated` (Apple's accelerated pixel format fails on this GPU, issue #21).
- **`gl*` calls** — `mgl_gl_interpose.c` (generated by `gen-interpose.py` from the 657 core functions MGL
  implements, with Khronos ABI from `glcorearb.h`) interposes each `gl*`. A **gate**: while the app's MGL
  context is current it routes to MGL, otherwise to Apple's real function (resolved with `RTLD_NEXT`), so
  AppKit's own GL during context setup is left alone. Needs library validation off (`amfi` / `ngreenlv`).

Regenerate the interpose after changing MGL: `python3 src/MGLShim/gen-interpose.py`.

## Status (1 Nov 2026)

- Proven: the same `NSOpenGLView` probe binary shows `Apple Software Renderer` run normally and **`MGL`
  (GL 4.6) on the Iris Xe** under the shim — at the 22-function proof. Scaling to all 657 core functions hit
  two bugs, both fixed in code: a link failure (Apple doesn't export some 4.2+ symbols → `-undefined
  dynamic_lookup`) and an infinite recursion (`dlsym` returned the interposed wrapper → use `RTLD_NEXT`).
  Pending the next on-Mac run to confirm the full self-test, then **OBS** is the target app.

## Running it (over git, no USB)

On the Mac, with MGL already built once (`tools/mgl-build.sh`, products in `~/VostroXe-MGL`):

```sh
cd ~/VostroXe && git pull
MGL_DIR=$HOME/VostroXe-MGL zsh tools/mgl-shim.sh            # self-test: probe → Apple vs MGL
MGL_DIR=$HOME/VostroXe-MGL zsh tools/mgl-run.sh /Applications/OBS.app   # a real app under the shim
```

Paste the terminal output back; on a crash the script prints the faulting backtrace inline.
